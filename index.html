Aula 1 Introdução ao Computador

O que é um Computador?

Um computador é uma máquina eletrônica que processa dados seguindo instruções específicas. Ele é composto por hardware (partes físicas) e software (programas).

História Breve

  • 1940s: Primeiros computadores (ENIAC)
  • 1970s: Computadores pessoais (Apple I)
  • 1980s: IBM PC revoluciona o mercado
  • 1990s: Internet populariza o uso
  • 2000s: Laptops e dispositivos móveis

Tipos de Computadores

  • Desktop: Computadores de mesa para uso geral
  • Laptop: Portáteis para mobilidade
  • Servidor: Para redes e aplicações empresariais
  • Workstation: Para trabalhos profissionais pesados

Evolução dos Processadores

  • 8086 (1978): 16 bits, 5-10 MHz
  • Pentium (1993): 32 bits, 60-200 MHz
  • Core 2 Duo (2006): Dual-core, 1.8-3.0 GHz
  • Core i7 (2008): Quad-core, hyperthreading
  • Ryzen (2017): Até 16 cores, arquitetura Zen

Aula 2 Componentes Internos

🔧 CPU (Processador)

O "cérebro" do computador que executa instruções.

  • Núcleos: Mais núcleos = melhor multitarefa
  • Frequência: Medida em GHz
  • Cache: Memória ultra-rápida interna
💾 Memória RAM

Armazena dados temporariamente para acesso rápido.

  • DDR4/DDR5: Tipos mais modernos
  • Capacidade: 8GB, 16GB, 32GB+
  • Velocidade: Medida em MHz
🔌 Placa-mãe

Conecta todos os componentes do computador.

  • Socket: Tipo de processador suportado
  • Slots: Para RAM, placas de expansão
  • Conectores: SATA, USB, áudio
💾 Armazenamento
  • HD: 500GB-18TB, mecânico
  • SSD: 120GB-8TB, flash
  • NVMe: Ultra-rápido, M.2
🎨 Placa de Vídeo
  • Integrada: No processador
  • Dedicada: NVIDIA/AMD
  • VRAM: 4GB-24GB
⚡ Fonte de Alimentação
  • Potência: 400W-1200W
  • Eficiência: 80+ Bronze/Gold
  • Modular: Cabos removíveis
🌡️ Resfriamento
  • Air Cooler: Ventoinhas e dissipador
  • Water Cooler: Líquido refrigerante
  • Pasta Térmica: Transferência de calor

Aula 4 Armazenamento de Dados

💿 HD (Hard Disk)

Armazenamento magnético tradicional.

  • Capacidade: 500GB a 18TB
  • Velocidade: 5400-7200 RPM
  • Vantagens: Baixo custo
  • Desvantagens: Lento, frágil
⚡ SSD

Armazenamento em memória flash.

  • Capacidade: 120GB a 8TB
  • Velocidade: 500-7000 MB/s
  • Vantagens: Muito rápido
  • Desvantagens: Mais caro
🚀 NVMe M.2

SSD ultra-rápido conectado diretamente à placa-mãe.

  • Capacidade: 250GB a 4TB
  • Velocidade: Até 7000 MB/s
  • Vantagens: Extremamente rápido
  • Desvantagens: Mais caro, aquece

Aula 7 BIOS e UEFI

O que é BIOS/UEFI?

Firmware que inicializa o hardware antes do sistema operacional.

Configurações Importantes

  • Ordem de boot
  • Configurações de memória
  • Temperaturas e ventoinhas
  • Overclock básico

Configurações Avançadas

  • XMP/DOCP: Overclock automático da RAM
  • Secure Boot: Segurança de inicialização
  • TPM: Módulo de segurança
  • Virtualization: Para máquinas virtuais

Aula 9 Drivers e Configuração

O que são Drivers?

Programas que permitem ao sistema operacional se comunicar com o hardware.

Tipos de Drivers

  • Chipset: Comunicação básica da placa-mãe
  • GPU: Placa de vídeo (NVIDIA/AMD)
  • Áudio: Som integrado ou placa dedicada
  • Rede: Ethernet e Wi-Fi

Ordem de Instalação

  1. Chipset (sempre primeiro)
  2. Rede (para baixar outros)
  3. GPU (NVIDIA/AMD)
  4. Áudio e periféricos

Onde Encontrar Drivers

  • NVIDIA: nvidia.com/drivers
  • AMD: amd.com/support
  • Intel: intel.com/support
  • Placa-mãe: Site do fabricante
